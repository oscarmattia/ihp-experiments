# ihp-experiments

Analog IC design experiments using the IHP SG13G2 open PDK.

## Quick start

```bash
./scripts/install-ihp-eda.sh
source ~/.local/share/ihp-eda/env.sh
./scripts/verify-ihp-eda.sh
```
